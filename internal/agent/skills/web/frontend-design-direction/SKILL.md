## When To Use

Use this skill when creating or improving the visual direction of a web app, ecommerce storefront, dashboard, landing page, or product UI.

## Instructions

- Anchor the design in the product domain: workflows, user intent, data density, trust cues, and realistic content.
- Choose layout before decoration. Prioritize hierarchy, scan paths, action placement, and responsive behavior.
- For operational apps and dashboards, favor dense, calm, repeatable interfaces over marketing-style sections.
- For storefronts and public pages, make the product or offer visible in the first viewport and keep purchase/contact actions clear.
- Use a restrained palette with purposeful accents. Avoid making the entire UI one hue family.
- Use existing UI primitives, icons, tokens, and spacing conventions before creating new visual systems.
- Include real states: loading, empty, error, hover, focus, selected, disabled, and success.
- Verify that text fits inside buttons, cards, nav, tables, and mobile layouts without overlap.
